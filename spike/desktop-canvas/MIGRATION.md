# PinDo 桌面便签画布迁移

技术验证版已在 Windows 10 LTSC 2019 上由用户确认：桌面应用可打开，
修正悬停焦点后的版本不再使应用消失，整体交互流畅。

## 窗口边界

- 桌面便签与右侧收纳区：一个透明的桌面层画布。画布空白处穿透到 Explorer 图标。
- 始终置顶便签：保持原有顶层原生窗口；否则单一桌面层画布无法同时位于应用上方。
- Dodo、提醒、设置：保留控制窗口及已有选择性鼠标穿透策略。
- 壁纸：独立于透明便签层实现，不在窗口背景上绘制不透明图片。

## 接入顺序

1. 已用 `PINDO_CANVAS_EXPERIMENT=1` 测试开关接入真实便签渲染器、原始 `notes.json` 状态与修订号。验证版的样例 JSON 不会导入正式数据。
2. 画布完成桌面挂载后才停止为 `desktop` 模式创建原生便签窗口；挂载失败立即回退到原有便签窗口。已添加两种模式的 Windows CI 检查。
3. 维持 `top` 模式原生窗口及现有独立的收纳区；仍需在 Windows LTSC 实机检验模式切换、附件堆叠、文件拖放、富文本、待办与时间轴。
4. 验证云同步往返的 ID 和数量不变；升级前先备份，避免重复便签问题回归。
5. Windows 10 LTSC 2019 上验证启动、锁屏恢复、Explorer 重启、多显示器和不同 DPI；通过后再提供测试通道开关。

正式切换的验收条件：桌面图标可双击；便签内可以输入、拖动、缩放；外部应用持续可见且无屏闪；
现有便签 ID/内容/数量不变；“始终置顶”、Dodo 与云同步行为保持可用；
任何挂载失败都能自动使用原来的多窗口模式。
