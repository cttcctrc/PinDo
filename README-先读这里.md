# PinDo 1.1.0-beta.5.2 · Windows 交互修复测试版

本包是完整源代码，未附已编译的 exe。退出旧版 PinDo，解压到新目录，运行 `Windows-一键打包.cmd`。打包完成后，在 `release` 中安装 `PinDo-Desktop-Test-1.1.0-beta.5.2-x64.exe`。便签仍存放在原来的用户数据目录，不需手动迁移。

beta.5.2 修正 beta.5.1 漏改的开发路径断言：之前把 `/dev/electron/windows-ocr.ps1` 写死为期望值，Windows 的 path.join 实际返回反斜杠路径。已使用 Windows 路径规则复现该断言失败，修复后同一模拟检查通过。新增实际路径解析器在 Windows/POSIX、空格目录和 UNC 路径下的验证，全部 33 项测试通过。未将此模拟验证称为 Windows 安装或实机测试。

## 本轮处理

| 反馈 | 代码改动 |
| --- | --- |
| Dodo 始终置顶、当前操作窗口最高 | Dodo 使用系统置顶；激活桌面便签时临时从 Explorer 提升，失焦后返回桌面。同一个窗口、同一份编辑内容，不因焦点切换重建。异步切层按最新焦点串行执行。 |
| 字体工具栏、Dodo 菜单、更多菜单不关闭 | 接入系统窗口 blur，清除选区、工具栏、菜单和选中态；同窗口空白点击也关闭。 |
| 整理项目反复要求重新拖入 | 在 drop 事件内同步取得真实路径；主进程保存文件信息。同名的旧无路径项目补全替换，重复拖入同一路径不再产生副本。 |
| 整体 UI 缩小不完整 | 补上右侧收纳栏设置同步、正文/标题缩放及遗留固定字号；去掉菜单重复缩放，避免定位与缩放叠加。 |
| OCR 不工作 | Windows 脚本从 ASAR 解包到真实路径；识别输入转换 BGRA8；尝试系统可用语言；无文字和服务启动失败分别提示，错误显示在按钮旁。 |
| 钉图出现白边 | 按实际图片比例创建透明窗口，超过屏幕时等比缩小；禁止手动拉出错误比例，保留拖动与右键关闭。 |
| 更多菜单显示不完整 | 限制弹层到窗口可见范围；窄/矮窗口可内部滚动；内容变化后重新定位。 |
| Dodo 菜单记住了底部滚动位置 | 每次打开回到顶部。 |
| 睡觉、沮丧缺失 | 恢复一份已保存的透明睡眠 WebP 循环和沮丧序列末帧；接入时间、任务数量、催办阶段和交互中断规则。详见下面的资产范围。 |
| 过去的截止时间可选 | 待办日历禁选过去日期；时分滚轮的过去值置灰禁用，保存时再次校验。时间轴仍支持记录历史。 |
| 收纳栏信息悬停后不消失 | DOM 离开和系统指针穿透事件均清理预览；严格悬停显示。 |
| 默认开机启动 | 安装版首次运行注册登录启动，后续退出不删除注册；只注册一次，尊重用户之后在 Windows 中关闭启动项的选择。 |
| 靠边拖动没有反馈 | 拖动中显示“松开收纳到右侧”或“松开隐藏 Dodo”；松开完成收纳。桌面整理不收纳，缩放不触发收纳。 |
| Dodo 收纳位置、名字和数量 | 补偿静态图透明边距；收纳时隐藏名字和数量，悬停显示并向屏幕内约束。 |
| 标题拖动、按钮点击冲突 | 未编辑标题使用抓手，可拖动；实际移动达到阈值才捕获鼠标；双击仍可编辑，编辑时为输入光标。按钮排除在拖动区域外，悬停或选中显示，失焦清除选中态。 |

## Dodo 资产范围

- 睡眠：22:00–次日 08:00、12:00–13:30，在没有正在操作或待显示提醒时使用找回的伸展睡姿循环；点击唤醒，操作后至少 30 秒才重新进入睡眠。
- 沮丧：非睡眠待机时，今日待办超过 10 个或催办阶段达到 03，显示已确认沮丧序列的最后一帧。
- 失落：超过 5 个或催办 02，目前暂用同一序列首帧静态姿态。
- 本次仅恢复一套可用睡眠循环，**尚未恢复完整三种睡姿随机切换、原失落循环及完整入睡/醒来过渡资产**。切换先使用透明度过渡。找到的入睡原图带实际棋盘格背景，未塞入程序冒充透明资产。
- 收起/展开仍按确认方案用静态图，不恢复原有问题的动画。

## 已完成检查与实际限制

- 31 项 Node 流程测试通过，包括焦点切层并发、旧路径补全/重复导入、钉图比例、日期边界、睡眠时间段、提醒中断、ASAR 外脚本路径，以及原有数据冲突、吸附、回收站和截图 DPI 测试。
- 30 个 JavaScript/CJS 文件语法检查通过，桌面结构检查通过。
- 当前环境不是 Windows，未做真实系统置顶、Explorer 挂载、开机启动、OCR 或拖动视觉验收；测试中的系统接口为模拟接口。也没有将源代码包描述为已完成实机验收的安装包。
- OCR 依赖 Windows 已安装的语言识别组件以及允许执行本地脚本的系统策略。本版不更改系统策略，不上传截图，也不接收费 OCR。若失败，按钮旁会给出具体错误。
- 右侧收纳栏当前在主显示器右侧。多屏环境请重点检查副屏移动、缩放和收纳。
- 开机启动仅在安装后的程序生效；开发启动 `npm start` 不注册启动项。
- 系统更新地址、代码签名仍未配置。

## 优先验收

1. 打开资源管理器，检查 Dodo 一直可见；点一张便签，操作后点资源管理器，检查便签按显示层级回到正确位置。
2. 标题单击拖动、双击编辑、右上角按钮单击；检查三者不相互干扰。
3. 菜单/工具栏打开后点击真正的 Windows 桌面或其他程序，检查能关闭。
4. 重新拖入一个此前报错的文件夹、快捷方式，确认没有重复卡片，点击可打开；退出重开后再测试。
5. 小/中/大 UI 分别检查收纳标签、日历、更多菜单；拖动到屏幕边缘检查提示。
6. 随手记截取横图、竖图分别钉住；截清晰中文和英文测试 OCR，若失败请保留具体错误文字。
7. 选择今天已过去的时分和昨天日期，确认不可选；确认时间轴仍可以设置历史日期。
